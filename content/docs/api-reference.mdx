The reference is **generated**, never typed. The source is the platform layer's `openapi.json`, produced from the running API and limited to partner operations. This site copies it with `npm run sync:public-api` and renders one page per operation under **API** in the sidebar, grouped by resource.

## The ten parts of every endpoint

Each generated page carries these, in this order. If the contract lacks one, the build fails rather than publishing an incomplete page.

1. **Purpose in one sentence**, with a link to the matching flow chart.
2. **Authentication and permission**: which key, which scope, which consent condition must hold.
3. **Request**: path, method, parameters, body with types, required and optional, example.
4. **Response**: fields with types, "unavailable" as a documented state, example.
5. **Errors**: every code with cause and action. Especially: consent missing, session closed, subject deleted.
6. **Pagination**: cursor or page, sort order, maximum sizes.
7. **Rate limits**: per key, per session, headers, behaviour on overflow.
8. **Idempotency**: which calls are repeatable, the header name, how long a key is valid.
9. **Version policy**: how the version is passed, lifetime, deprecation with date.
10. **Data protection note**: which data the call touches, how long it stays, whether it can be exported and deleted.
