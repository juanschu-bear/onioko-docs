This page is the honest counter. Numbers and states come from `public-api/STATUS.json`, synced from `anima-core`. When a resource is released, its operations appear in the API reference automatically and the counter changes.

<StatusBoard />

## How to read the states

| State | Meaning |
| --- | --- |
| <Status state="released" /> | Part of the public contract. Operations are in the API reference. Covered by the version policy. |
| <Status state="migrating" /> | Exists in a product today and is being moved into the platform layer. Not callable by partners yet. |
| <Status state="planned" /> | Defined as a partner resource, not yet released. May exist internally. |
| <Status state="internal" /> | Exists in the code and is deliberately not part of the public contract. |
